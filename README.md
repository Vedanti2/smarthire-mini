# SmartHire Mini

## Project Overview

SmartHire Mini is a simple job portal application built using HTML, CSS, and JavaScript.

## Features

- Display available jobs
- Job application form
- Dynamic job listing
- Form validation
- Responsive UI

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Run

1. Download the project.
2. Open index.html in a browser.
3. Browse jobs and submit applications.

## Future Enhancements

- Login System
- Database Integration
- Resume Upload
- Search and Filter Jobs
